# HOJ 智能编程学习系统

## 1. 项目目标

状态核对：2026-11-07。本文说明当前功能入口与操作；实现、验证、用户验收分别记录，当前状态及证据以 [TODO](./TODO.md) 为准。产品要求与长期约定仍见 Obsidian《HOJ 项目记忆》，当前在线状态需实际检查。

本项目面向 ICPC 集训队，目标是在 HOJ 的题库、训练、提交记录和学习资料之上，增加以下相互配合的功能：

1. **RAG 知识库系统**：管理内部题目、题解、讲义、PDF、Markdown、TXT 和视频转写内容。
2. **AI 教学问答系统**：只服务于编程学习，支持全局问答和题目上下文问答。
3. **AI 学习工作台**：独立于问答页面，提供学习计划、薄弱点分析、题目推荐和学习反馈。
4. **跨平台训练与个人远程提交**：Codeforces、AtCoder、牛客账号关联、归属验证、分平台统计、明确去重、同步、本人会话授权与双语题面；真实源站提交效果按 TODO 单独验收。
5. **客观题练习**：独立于编程判题的录题、作答、判分、解析和错题复习；前后端同时交付，题型与答案开放规则见 [数据模型与 API](./08-data-model-and-api.md)。

比赛进行期间，正式或虚拟参赛用户的所有 AI 入口由服务端禁用，其他用户可用。RAG 检索内部已授权资料；资料片段须经用户明确勾选才发送给本人配置的模型。供应商可能具有的联网能力不代表本站已实现联网检索，也不把联网内容当作内部资料。

## 2. 已确认的产品边界

### AI 的身份

AI 是算法竞赛教练和学习助手，不是通用聊天机器人。回答应优先引导学生思考：

- 先确认题意和知识点；
- 再给出分层提示；
- 引导学生自己推导；
- 最后才在允许的场景下给出较完整的思路；
- 默认不直接替学生完成题目。

### 两个前端入口

- **AI 问答**：即时提问、题目上下文问答、提交代码分析、多轮对话。
- **学习工作台**：学习计划、今日任务、掌握度、薄弱点、推荐题目、错题复盘。

### 知识范围

- RAG 知识库只包含内部数据和管理员允许上传的资料。
- 普通题目、训练题目和内部课程资料可以进入知识库。
- 当前系统视为一个 ACM 集训队整体，不设计多租户团队知识库；但仍保留来源和权限字段，以便保护比赛题、私有题和管理员资料。

## 3. 推荐的总体形态

不要把 Python RAG 原型的代码直接复制到 HOJ 的 Java 代码中。推荐拆成两个服务：

```text
Vue2 前端
    │
    ▼
HOJ Spring Boot 后端
    ├── 用户认证、权限、比赛状态
    ├── 学习行为与学习工作台数据
    ├── AI 助教、比赛限制、本人模型调用与审计
    ├── 三平台账号、同步与个人远程任务
    └── 调用 Learning OS RAG 服务
             ├── 文档解析、清洗、切片
             ├── Embedding
             └── Qdrant 检索、版本隔离与引用
```

HOJ 后端是业务入口；模型调用由 Java 后端执行，Key 加密保存在服务端。前端通过本站接口访问模型、题源和内部检索，不直接连接 Qdrant。本站助教当前使用 OpenAI 兼容 API；Python 原型中的原生 Anthropic 适配不代表已接入本站。

## 4. 当前功能与验收入口

本地站点通常为 `http://localhost:8080`，下列路径追加在当前站点域名后使用。个人操作须先登录；后台操作须有对应管理权限。

| 功能 | 入口 | 可以核对的操作 |
| --- | --- | --- |
| 预置与自建标签 | `/admin/problem/tag`；训练分类 `/admin/training/category` | 浏览预置目录、新增自建项；前台 `/problem` 按标签筛题 |
| 三平台账号与统计 | `/setting` → 跨平台账号关联；或本人 `/user-home` → 跨平台训练记录 | 选平台并关联、验证账号归属、请求同步，查看分平台与去重统计 |
| 能力分布与推荐 | 本人 `/user-home` | 切换知识点分布来源；“下一组训练”更新推荐、保存本组，在“我的训练清单”刷新进度、改名或归档 |
| 本人模型助教 | 全站“AI 助教”浮窗 → 模型设置 | 配置 HTTPS 基础地址、模型与 Key；按需勾选题面或画像。保存配置与真实问答分别验收 |
| 个人远程提交与双语 | 已验证账号旁“会话授权”；公开题 `/problem/:problemID` | 在产品内授权本人源站会话，主动提交代码；公开独立远程题可切换原文与已核对译文 |
| 题源维护与同步 | `/admin/problems?type=remote` | 切换三平台、更新目录、获取题面、检查原文与译文及开放状态；个人记录的“刷新”与“请求同步”分别使用 |
| 客观题与混合卷 | `/objective`、`/papers`；后台 `/admin/objective`、`/admin/papers` | 单题练习或整卷作答，按管理员设置查看结果与解析；编程与非编程题各自保存作答 |
| 内部知识库 | `/knowledge`；后台 `/admin/knowledge` | 管理员维护资料与发布版本，用户检索可见资料、查看引用与原件；问答外发片段需明确勾选 |

跨平台关联使用源站公开资料中的校验码验证归属：CF 为 Organization，AtCoder 为 Affiliation，牛客为公开简介。资料设置里的历史 CF 用户名只是资料字段，不能替代正式账号归属验证。模型 Key 与授权会话只在产品内填写；源站登录在源站页面完成。

本站已实现前后端学习功能以及 Markdown/TXT/PDF/视频资料处理、版本、异步入库与权限过滤。具体已执行验证和未完成条件只在 [TODO](./TODO.md) 维护；资料检索详细质量与性能记录位于 `D:/learning-OS-RAG/docs/hoj-evaluation.md`。

仍需完成或另行验收的内容：RAG 多证据覆盖、逐结论依据与拒答、完整性能和资源；推荐效果与长期同步稳定性；牛客无 job 标识时完整源码自动核对。本人真实模型及三平台 AC/WA 按用户决定延期。原生更多供应商、站内联网和多 Agent 属于后续独立范围，不因原型有相关代码而视为已接入。
