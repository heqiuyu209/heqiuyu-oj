## 推荐实现顺序

```text
现有系统理解
  → RAG 本地最小闭环
  → HOJ 后端对接
  → 题目 AI 助教
  → 学习工作台
  → 多模型治理
  → CF VJ
  → 评估与上线
```

不要一开始同时开发 RAG、学习推荐和远程判题。它们分别属于知识检索、学习分析和外部平台集成，调试边界不同。
